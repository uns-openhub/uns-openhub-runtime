# Contributing

`uns-datahub-runtime` is generated by the private `uns-datahub-tools`
repository. Make source changes there and regenerate this bundle instead of
hand-editing generated binaries or controller artifacts here.

For repository-only documentation or validation changes, use a short-lived
branch and a pull request into `main`. Never commit `.env`, secret files,
registry credentials, production configuration, or customer data.

Before requesting review, run:

```bash
bash scripts/verify-runtime.sh
```
